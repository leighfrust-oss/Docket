### DOCKET 
Docket: a simple, offline Windows app for managing documents, tasks, a document register and everyday office tools. Your data stays on your computer.

**Documents:** drawers, folders, links, trash and file uploads

**Status board:** tasks, concerns, signatures and suppliers
**Document Register:** tracks versions, status and review dates

Monthly report you can print or save as PDF

**Tools:** calculator, encrypted password vault, password generator, date calculator, percent and tax, unit converter, text tools, file name builder and templates

**Calendar with reminders, light and dark mode, optional PIN lock**

**Everything is stored on your computer, with no account or internet needed**

**Install:** download Docket Setup 1.0.0.exe below and run it.
